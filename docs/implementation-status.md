# 备份配置门槛：发布前本地验证（2026-10-15）

本次修改为备份和恢复演练增加统一的本地配置门槛，不新增数据库迁移、公开 API 或仓库内 CD。GUI 仍只配置头像 S3；独立备份 S3 保持服务器 Secrets 配置。

## 行为与交付

- 服务器启用意愿、配置完整性与 GUI 演练频率分别处理。未配置时返回 `not-configured`，关闭时返回 `disabled`；不创建恢复锁、目录、子进程或失败/告警记录。
- 非空非法配置或权限错误仍按脱敏错误处理；完整配置后的网络、鉴权和存储故障按失败告警，保留 WAL，不静默禁用。
- 预发布可使用受保护的空 `SECRET_DIR/backup` 目录启动，但此时没有备份保护。生产仍要求启用、配置完整的独立 S3。
- 备份专用目录只读挂载给 DB 和维护容器，不向 Web、Worker、扫描或 Beat 暴露。没有虚假密钥文件；挂载不自动创建宿主路径。
- 四镜像清单、不可变摘要、仅 dev 标签触发 CI、回环 HTTP 与 WhiteNoise 资源交付边界不变。

## 发布及外部边界

本文件记录提交前本地验证。后续新提交、新 dev 标签的远端 CI、四镜像摘要与预发布部署结果须另行核验；不能沿用旧标签或旧镜像声称修复已部署。

已安装的 Nginx/NginxUI 保持未启动、未配置。正式 DNS/TLS、SMTP、Turnstile、OAuth、Webhook 和独立异地备份不由上述本地测试证明。预发布缺少备份 S3 时必须明确交接“当前无备份保护”；补齐后重新创建数据库和维护服务，并验证首次全量备份。
